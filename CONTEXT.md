# Personal iPad Notes

A personal notebook app for handwritten and typed notes on one iPad.

## Language

**Notebook**:
A named collection of pages in a defined order.
_Avoid_: Note, document when referring to the complete notebook.

**Page**:
One writing surface within a notebook.
_Avoid_: Note when referring to one page.

**Folder**:
A named group that contains notebooks. It can contain more than one notebook.
_Avoid_: Notebook when referring to this group.

**Unfiled**:
The built-in folder for notebooks that the user has not placed in a custom folder.
_Avoid_: General when referring to this folder.

**PDF notebook**:
A notebook created from an imported PDF, with one page for each PDF page at import.
_Avoid_: PDF file when referring to the notebook and its added content together.

**Text box**:
A movable area of keyboard-entered text on a page. The user explicitly selects it to edit its text.
_Avoid_: Text section when referring to this movable content.

**Trash**:
The location for deleted items that can still be restored.
_Avoid_: Permanent deletion when referring to moving an item here.

**Ink**:
Handwritten marks made with a drawing tool.
_Avoid_: Typed text when referring to these marks.

**Typed text**:
Text entered with a keyboard.
_Avoid_: Ink when referring to this text.

**Object eraser**:
An eraser that removes a complete ink stroke it touches.
_Avoid_: Regular eraser when referring to this mode.

**Partial eraser**:
An eraser that removes only the part of ink it touches.
_Avoid_: Object eraser when referring to this mode.

**Scratch erase**:
A scratch-and-hold writing gesture that removes handwritten ink. It does not remove text boxes, shapes, or original PDF content.
_Avoid_: Scribble when referring to this feature; Scribble also names Apple's handwriting-to-text feature.

**Lasso**:
A tool that selects complete ink strokes, text boxes, and shapes within a freehand loop or box for movement or resizing. Original PDF content is not part of this selection.
_Avoid_: Eraser when referring to this tool.

**Selection**:
The set of page items currently selected for an action. Items in a mixed selection move together and resize proportionally.
_Avoid_: Notebook when referring to selected page content.

**PDF export**:
A PDF copy of notebook pages, including their visible writing and added content.
_Avoid_: Editable backup when referring to this copy.

**Editable backup**:
A saved copy from which the app can restore editable notebook content.
_Avoid_: PDF export when referring to this copy.
