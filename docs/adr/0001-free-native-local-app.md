# Free native app with local notes

Build a native iPadOS app for one person, with local notes and no paid service or developer membership. A web app would avoid native signing limits, but it would not meet the user's native-app requirement. The user accepts the seven-day build and installation cycle of Apple's free Personal Team method rather than a paid membership. Keep this constraint when choosing the app's storage, tools, and update process.

The user accepted this trade-off in the first design interview round. [Apple Personal Team limits](https://developer.apple.com/help/account/basics/about-your-developer-account).
